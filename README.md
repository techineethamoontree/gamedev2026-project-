# gamedev2026-project-
Lab 5: First 3D Game

โปรเจกต์เกม 3D Platformer พัฒนาด้วย Godot Engine 4.7.2 สำหรับวิชา Computer Game Development

🎮 เล่นเกม

👉 คลิกที่นี่เพื่อเล่นเกม

📖 เกี่ยวกับเกม

เกมแพลตฟอร์ม 3D ธีมครัว/ร้านอาหาร ต่อยอดจาก 3D Platformer Starter Kit โดยผู้เล่นควบคุมตัวละคร Food Worker กระโดดข้ามเคาน์เตอร์และเฟอร์นิเจอร์ในครัว หลบสิ่งกีดขวาง เก็บไอเท็มให้ครบ แล้วเดินทางไปยังประตูเพื่อผ่านไปยังด่านถัดไป

วิธีเล่น
ปุ่มลูกศร / W,A,S,D — เดิน/วิ่ง
Space (หรือปุ่ม Jump) — กระโดด (กดซ้ำกลางอากาศเพื่อ Double Jump)
เก็บเหรียญให้ครบทุกเม็ดในฉาก เพื่อปลดล็อกประตู (เปลี่ยนจากสีแดงเป็นสีเขียว)
🛠️ พัฒนาด้วย
Engine: Godot 4.7.2 (GDScript)
ตัวละคร: Food Worker by J-Toastie (แทนที่โมเดล gobot ต้นฉบับ พร้อมปรับ Animation ให้เข้ากับชุดท่าทางเดิม: Idle, Sprint, Jump)
การตกแต่งฉาก: ธีมครัว/ร้านอาหาร ใช้โมเดลจากชุด Restaurant Bits โดย Kay Lousberg (poly.pizza)
โมเดลทั้งหมด: สไตล์ Low-Poly เพื่อควบคุมขนาดไฟล์
ระบบเกมเพลย์หลัก
ระบบนับไอเท็ม/คะแนน (GameManager.gd) ตรวจสอบว่าเก็บครบตามจำนวนในฉากหรือยัง
ประตู (Door.tscn) เปลี่ยนสถานะเมื่อเก็บไอเท็มครบ และเปิดทางไปด่านถัดไป
